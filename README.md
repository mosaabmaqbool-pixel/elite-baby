# ELITE BABY — متجر البيبي

نسخة متجر مخصصة للشعار الذي أرفقه المالك، بواجهة عربية RTL وألوان التركواز والكريمي. يتضمن المتجر المنتجات والتصنيفات والخيارات والسلة والمفضلة والطلبات والتوصيل والكوبونات، ولوحة إدارة وصلاحيات الموظفين وحسابات العملاء ورفع الصور.

## حالة النسخة

المنتجات والأسعار ورسوم المنتجات المعروضة توضيحية، والرسوم SVG ليست صورًا لبضاعة فعلية. الشعار الأصلي مستخدم كما هو. وضع الاختبار مفعّل حتى تتم إضافة صور وبيانات المنتجات والأسعار والشحن الحقيقية. لا تتضمن الحزمة أي حسابات أو جلسات محفوظة، ولا اتصالًا بمتجر سابق أو إعدادات واتساب حقيقية.

## التشغيل

- المتطلبات: Node.js 22.13 أو أحدث وpnpm 11.25.0.
- نفّذ `pnpm install --frozen-lockfile` ثم `pnpm build`.
- أنشئ قاعدة D1 محلية فارغة مرة واحدة:

```sh
pnpm exec wrangler d1 execute DB --config dist/server/wrangler.json --local --persist-to .wrangler/state --file database-empty.sql
```

- انسخ `.env.example` إلى `.dev.vars` واضبط `SITE_URL` على عنوان المعاينة، وأنشئ قيمتين عشوائيتين مستقلتين لـ `ADMIN_SETUP_KEY` و`CUSTOMER_OTP_SECRET` باستخدام:

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

- نفّذ `pnpm dev` ثم افتح `/admin/setup` لإنشاء أول مسؤول برمز الإعداد الجديد. لا يوجد بريد أو كلمة مرور افتراضيان.
- لا تطبق `database-empty.sql` على قاعدة موجودة، ولا تجمع بين استيراده وتطبيق ملفات migrations على القاعدة نفسها.

## الاستضافة

يحتاج التطبيق Cloudflare Workers مع قاعدة D1 بربط `DB` وتخزين R2 بربط `MEDIA`. اضبط `SITE_URL` في متغيرات الاستضافة وقت التشغيل ثم انشر النسخة. ملف الاستضافة في هذه الحزمة لا يحتوي على معرّف مشروع محفوظ.

لإرسال تنبيهات الطلبات أو رموز دخول العملاء عبر واتساب، أضف بيانات Meta وقوالبك الخاصة وفق `.env.example` وملفات `docs/`. لا توجد بيانات اتصال حقيقية مرفقة.

## التخصيص

- التصميم: `app/baby-storefront.css`.
- الواجهة: `components/store/home.tsx` و`header.tsx` و`footer.tsx`.
- المحتوى الافتراضي: `lib/store-config.ts`، والكتالوج الأولي: `lib/catalog.ts`.
- الشعار: `public/images/elite-baby-logo.jpg`، ورسوم المعاينة: `public/images/baby-*.svg`.
- تُدار المنتجات والمحتوى والطلبات والشحن والصور من لوحة الإدارة بعد إنشاء حسابك.
- بيانات التواصل غير محددة حتى يضيفها المالك. لا توجد خدمة بريد لاستعادة كلمة المرور؛ الاستعادة بمساعدة مسؤول آخر وفق آلية المشروع.

## التحقق

نجح TypeScript واختبارات الإدارة والمتجر والعملاء في قواعد مؤقتة. رسائل واتساب في الاختبارات وهمية، ولم تُرسَل رسائل حقيقية. الفحص البصري للمتصفح غير متاح في بيئة المعاينة.

لا تنشر أو توزّع ملفات `.dev.vars` أو `.env` أو قواعد بيانات فعلية أو مجلدات `.wrangler` أو `node_modules` أو بيانات حسابات حقيقية.
